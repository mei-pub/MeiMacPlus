脚本 · Scripting

MeiMacPlus 内嵌了 Hammerspoon 兼容运行时（官方 1.1.1，92 个原生模块全部可用）。你的 init.lua、Spoons、社区脚本无需修改即可运行。

脚本目录（优先级从高到低）

① 设置里自选的目录  ② ~/.hammerspoon（存在即沿用，Hammerspoon 老用户零迁移） ③ MeiMacPlus 默认目录（首次开启会生成示例）。

试一下

-- ⌥⌘Y 弹通知
hs.hotkey.bind({"alt","cmd"}, "y", function()
  hs.notify.show("MeiMacPlus", "Hello", "from Lua")
end)
-- 前窗口靠左半屏
hs.hotkey.bind({"ctrl","alt"}, "left", function()
  local w = hs.window.focusedWindow()
  if w then w:moveToUnit("[0,0,0.5,1]") end
end)

权限提示

脚本触发的系统权限（辅助功能/屏幕录制/摄像头等）以 MeiMacPlus 名义申请，授权一次长期有效。

与官方 Hammerspoon 的差异

有意不内置：Sparkle 自动更新、Sentry 崩溃上报；hs.console 的窗口级透明度/背景色未生效（颜色/字体已生效）。

外部通道：AppleScript（hs.allowAppleScript(true) 后 osascript -e 'tell app "MeiMacPlus" to execute lua code "…"）、 服务菜单"Send to MeiMacPlus"、快捷指令"Run Lua in MeiMacPlus"、 hs.ipc.cliInstall() 安装终端 hs 命令。

Scripting

MeiMacPlus embeds the Hammerspoon runtime (official 1.1.1 — all 92 native modules included). Your init.lua, Spoons and community scripts run unmodified.

Script directory (priority order)

1) the folder chosen in Settings · 2) ~/.hammerspoon (reused as-is when present) · 3) MeiMacPlus's default (seeded with a starter script on first enable).

Try it

hs.hotkey.bind({"alt","cmd"}, "y", function()
  hs.notify.show("MeiMacPlus", "Hello", "from Lua")
end)

Permissions

System prompts triggered by scripts (Accessibility / Screen Recording / Camera …) are requested by MeiMacPlus; grants persist across launches.

Differences vs. upstream

Deliberately excluded: Sparkle auto-update, Sentry crash reporting; window-level alpha/background of hs.console (colors & font do apply).

External channels: AppleScript (after hs.allowAppleScript(true)), the "Send to MeiMacPlus" service, the Shortcuts action "Run Lua in MeiMacPlus", and the hs CLI via hs.ipc.cliInstall().
